# 智能空开 MCU 选型方案对比表（完整定版 2026-11-09）

> **选型结论（2026-11-12 项目负责人定案）：方案 1 GD32F103RCT6。** 本表为决策过程与依据存档（资源账 / 三方案对比 / 价格核查 / 引脚对照），定案已落入立项书 V2.0（5.2 主控选型）。

> 关联文档：《研发项目立项书_智能空开通讯模组替换_2026-11-04.md》（V1.9 定稿）。
> 本表为 MCU 选型决策材料的唯一完整版本，后续修订在本文件上进行并升日期。

## 一、决策前提

**产品目标形态（两方案相同）**：一块 PCB；LoRaWAN 可变频率通讯模组 + 频点现场配置；按客户需求贴装蓝牙芯片与配套元器件（含蓝牙 OTA 暂存 flash），实现蓝牙状态展示与控制、蓝牙固件升级（OTA）。

**必须更换 MCU 的原因（现款 GD32F103C8T6：64K Flash / 20K RAM，已用 28K / 8K）**：

1. 蓝牙功能模块预估 +20K Flash / +13K RAM，合计 48K / 21K——**RAM 超限 1K（21K > 20K），硬件上装不下**；
2. 48 脚封装仅 3 路串口且已全部占用（LoRa / 485 / 调试），蓝牙没有第 4 路可接。

因此"不换 MCU、仅串口配置"的方案出局，对比在以下两个方案之间进行。

## 二、主对比表

| LoRaWAN 主线能力（可变频率模组、频点现场配置、看门狗与门限设置双满足） | 完整支持 | 完整支持（固件需跨系列移植） |
| 与定稿立项书 V1.9 的关系 | 完全兼容，选型结论补入立项书即可 | 兼容，但需在项目计划中补充固件移植工作量与专项风险 |

| 每颗价差 | 基准 | 贵 25 ~ 33 元（约 4 ~ 6 倍，按现货/分销价口径） |

| 在产产品线使用现状 | GD32F103 大容量款全线仅空开拟用，属孤立料号（现款 GD32F103C8 也只有空开主线在用） | STM32L431RCTx 已是地磁停车传感器、电磁阀控制器、垃圾满溢传感器三条产品线的现役主控（三仓 Keil 工程器件名逐字核实），空开加入后四线统一备料 |
| 产品线协同 | 无协同 | 差分 OTA 参考设计可直接移植（地磁差分 OTA 评审即针对 L431）；统一备料摊薄四条线的库存与议价 |
| 固件一次性开发代价 | 低：同为 GD32F10x 固件库，改启动文件、器件型号、时钟配置复核，业务代码不动 | 中低：跨系列移植（GD32F10x 库 → STM32L4 HAL），但电磁阀与垃圾满溢仓库有现成 STM32L431 外设驱动，结构同源可大量复用（复用程度以开发启动时评估为准） |
| 固件长期维护成本 | GD32F10x 体系全线仅空开一条线使用：驱动缺陷、库升级、踩坑经验全部空开独担 | 并入 L431 体系，与地磁/电磁阀/垃圾满溢四线共享：一次修复四处受益；团队已有 10 条 ST 系产品线的开发维护经验 |
| 引脚兼容性（同为 LQFP64，详见第三节附表） | 五路串口中 3 路物理脚号与 L431 恰好相同（第 1 路 PA9/PA10@42/43、第 3 路 PB10/PB11@29/30、第 4 路 PC10/PC11@51/52）；485 串口（PA2/PA3，GD 在脚 16/17、L431 在脚 21/22）与 SWD 调试脚（PA13/PA14，GD 在脚 46/49、L431 在脚 34/37）错位 | 同一事实的另一面：从 GD 布线迁移到 L431 仍需重新设计主控区，两方案互换不改板不成立 |
| 硬件设计代价 | 主控区按 48 脚 → 64 脚重新布局（本次立项本就重新设计 PCB，属正常改版内容）；选型询价时同步确认 GD32F103 系列同封装（48 脚）大容量型号（128K/256K 版）是否有货，若有货可直接原位替换、主控区布局无需改动 | 主控区同样按 64 脚重新布局，另加外设引脚重新映射；可参考地磁/电磁阀/垃圾满溢三块现成板的主控区设计 |
| 串口资源（蓝牙需独立第 4 路；现款 3 路已占满） | 5 路（USART0/1/2 + UART3/4），满足 | 4 路常规串口（USART1/2/3 + UART4）+ LPUART1，满足；封装下引脚可用性以原理图设计确认 |
| 实施代价汇总 | 开发工作与既有任务合并即可完成，无新增独立开销 | 驱动可复用后，剩余增量主要是移植整合与整机全量回归 |
| 主要风险 | 单颗成本较现款 +30%；封装 48 → 64 脚变化 | 现货价格波动；GD32 与 STM32 两套 MCU 体系并行维护 |
| **结论** | **推荐方案（基于当前已核实的现货/分销价格）**：资源够、与定稿立项书承诺完全匹配、成本与实施代价最稳 | **两可、待一个决定性数字**：四线统一备料已是既成事实——三线合计采购量的 ST 合约报价是决定性数字（历史合约价口径约 ￥10）。报价回到 ￥12~19 区间，方案 2 凭四线统一备料 + 驱动复用 + OTA 设计直接移植反超；仍在 ￥30+ 则方案 1 最稳 |

## 三、附表：关键功能引脚对照（同为 LQFP64 封装）

| 功能 | GD32F103RCT6（方案 1） | STM32L431RCT6（方案 2） | 是否同位 |
|---|---|---|---|
| 第 1 路串口（LoRa 模组） | 脚 42/43 = PA9/PA10（USART0_TX/RX） | 脚 42/43 = PA9/PA10（USART1_TX/RX） | 恰好同位 |
| 第 2 路串口（485 总线） | 脚 16/17 = PA2/PA3（USART1_TX/RX） | 脚 21/22 = PA2/PA3（USART2_TX/RX） | 错位 |
| 第 3 路串口（调试口） | 脚 29/30 = PB10/PB11（USART2_TX/RX） | 脚 29/30 = PB10/PB11（USART3_TX/RX） | 恰好同位 |
| 第 4 路串口（蓝牙） | 脚 51/52 = PC10/PC11（UART3_TX/RX） | 脚 51/52 = PC10/PC11（UART4_TX/RX） | 恰好同位 |
| SWD 调试 | 脚 46/49 = PA13/PA14（SWDIO/SWCLK） | 脚 34/37 = PA13/PA14（SWDIO/SWCLK） | 错位 |
| BOOT0 / 复位 / 电源组 | BOOT0=脚 60、复位=脚 7、电源五组（12/13、18/19、31/32、47/48、63/64） | 排布不同（以 ST 数据手册 DS12025 表 9 为准，本轮未逐脚核实） | 不同 |

对照结论：4 路常规串口有 3 路物理位置恰好相同，但 485 串口和调试口这两个关键脚错位，加上 BOOT0、复位、电源组排布不同——两方案的主控区电路不能互相照搬，将来互换需要二次改版。

## 四、待确认项

1. **三线合计采购量的 ST 合约报价**（决定性数字，选型评审第一步先拿）；
2. 两颗芯片价格以正式采购询价终核（现货价 ≠ 批量合约价）；
3. GD32F103 48 脚同封装大容量型号（128K/256K 版）可得性；
4. 蓝牙功能模块 +20K/+13K 为预估，与其他新增功能消耗以固件编译产物实测对账；
5. STM32L431 引脚对照以 ST 数据手册 DS12025 表 9 全表复核（含 BOOT0/复位/电源组）；
6. 64 脚封装下串口引脚可用性以原理图设计确认。
