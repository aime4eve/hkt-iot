# 测试与验收方案（空开二代基座首产品）

> 关联文档：《研发项目立项书_第二代通讯基座_2026-11-12.md》（V3.0）。
> 本文档自立项书 V2.0 第 5.4 节（测试方案）与第十章（验收标准）独立成文（2026-11-12，按"立项只交代需求"原则移出）；测试集内容与验收承诺自 V1.2 起逐轮评审沉淀，此处完整承接，后续修订在本文件进行。

## 一、测试方案

测试集按固件代码可达行为设计，每条用例对应明确的代码路径与判定标准。**通用前置条件**：空开地址分配后首次手动合闸置位远程控制使能位（现固件硬性前提），之后的远程通断用例才有效；EU868 / US915 两频段各执行一遍功能与通信集，长稳测试按主出货区域频段执行。**配置口径**：F / C / P / R 四集在主线配置（不含蓝牙）样机上执行，通过即为主线交付与结项的验收依据；B 集仅在蓝牙款样机执行，作为蓝牙订单交付的放行条件。**能力通道口径（V3.0）**：除 OTA 升级仅经蓝牙外，参数配置 / 设备控制 / 数据遥测均为 LoRaWAN 与蓝牙双通道——参数配置含调试串口、LoRaWAN 下行远程指令、蓝牙 APP 三入口（C-06 / C-09 / B-09 分别覆盖）。样机配置：研发样机按蓝牙款 / 主线款各半配置（建议各 10 台，M1 定）。

### F 功能回归集（F-01 ~ F-19，覆盖全部下行命令与上报路径）

| 用例 | 测试项 | 判定标准 |
|---|---|---|
| F-01 | 地址编码模式进入/退出（0x00，下行指令入口） | 平台下发 0x00，由通讯板经 485 向空开发送进入/退出命令；两个方向各执行 ≥50 次，LoRaWAN 应答、485 响应与空开实际模式一致（对应 V7.12"概率无效"修复项）；另验证进入后 60 s 自动退出。本用例不以空开本体按键作为进入方式；若现场工艺要求进入模式后逐台按键分配地址，另列现场工艺验证 |
| F-02 | 上报周期设置（0x01）边界 | 下发 0 = 停报；1 ~ 299 s 归一化到 300 s；36000 s 上限截断生效；断电重启后周期保持（flash 参数持久化验证） |
| F-03 | 单台通断（0x03） | 在线 + 远程使能才执行并应答；在线但未使能时不动作；覆盖分闸、合闸双动作 |
| F-04 | 广播通断（0x03，addr=0xFF） | 逐台核对执行结果与应答一致性 |
| F-05 | 恢复出厂（0x04） | 各执行 ≥50 次（概率无效回归项）；恢复后需重新走地址分配流程验证 |
| F-06 | 读阈值（0x05） | 单台应答 40 字节阈值数据完整；非法地址（addr ≥ 10）无应答 |
| F-07 | 读实时数据（0x06） | 单台应答 59 字节实时数据 + 远程使能位完整 |
| F-08 | 查询在线状态（0x08） | 返回 16 位位图与实际上线空开一致 |
| F-09 | 批量通断（0x09） | 至少一台成功才返回结果应答；全部离线时不应答 |
| F-10 | 批量查询状态（0x0A） | 返回分合闸 + 远程使能双 16 位位图正确 |
| F-11 | 漏保自检（0x0B） | 仅对合闸状态空开执行；应答含执行结果 |
| F-12 | 电量清零（0x0C） | 按"解锁 → 高字节清零 → 低字节清零"顺序执行；单台与 addr=0xFF 全部两种模式 |
| F-13 | 版本查询（0x0D） | 返回硬件/软件版本号与新固件一致；boot 串口横幅频段标识与编译配置一致 |
| F-14 | 0xEE 透传下行 | 透传封包正确转发至 485 总线；V7.12 封包长度检查保留：超长线丢弃并日志记录，不得触发缓冲区溢出 |
| F-15 | 0xEE 透传上行 | 485 回包按 AA EE 头 + CRC + 55 尾封包上报，平台解码一致 |
| F-16 | 周期上报 | 按 F-02 设定周期上报全部在线空开实时数据；周期误差 ≤ ±5% |
| F-17 | 事件即时上报（change_mask） | 三类事件（报警 / 开合闸变化 / 远程使能变化）均触发即时上报且只上报变化空开；以 30 秒轮询周期为上界计量时延 |
| F-18 | 满级联 | 10 台级联下周期上报、批量命令、F-17 事件上报全项复测 |
| F-19 | 异常帧 | CRC 错、帧长错、非法命令码均不应答不死机 |

### C 通信性能集（C-01 ~ C-09）

| 用例 | 测试项 | 判定标准 |
|---|---|---|
| C-01 | 冷启动入网 | 连续 100 次，RSSI ≥ -100 dBm 环境成功率 ≥ 99% |
| C-02 | 入网失败退避 | 断网环境下记录入网超时 → 退避 → 重试时序，与现款基线偏差 ≤ ±20%（现款利尔达线约 120 s 超时 + 10 分钟退避） |
| C-03 | 连续发送失败判离线（灰盒：故障注入 + 内部状态观测 + 平台复核） | 通过测试固件故障注入或模组状态脚工装制造发送失败，以 SWD 或测试版串口日志观测 `send_failcnt`、`joinState`、`lwrb_write_count`：第 1～4 次连续失败不判离线；第 5 次在同一失败处理周期内判离线、清空缓冲区并设置 10 分钟重连时间；插入一次成功应清零失败计数；恢复入网后平台无旧帧补发。不得以平台缺帧数代替固件内部发送失败计数 |
| C-04 | 环形缓冲区溢出（灰盒：离线攒包 + 调试串口注入） | 保持 `joinState = 0` 停止缓冲区消费，且不得触发连续 5 次发送失败清缓冲；通过 USART2 调试口注入带序号的 100 字节数据帧，每帧间隔 >50 ms，连续注入 21 帧。按每帧 101 字节（含 1 字节长度）计算，20 帧占用 2020 字节、剩余 27 字节，第 21 帧触发丢弃最旧帧；最终仅保留第 2～21 帧，`lwrb_write_count = 20`、`lwrb_get_free() = 27`，最新帧完整、回绕顺序正确，无死机或越界 |
| C-05 | 弱场梯度 | 衰减器 10 dB 步进扫至链路极限，记录各档丢包率与极限 RSSI，不劣于现款基线 |
| C-06 | 信道计划与频点配置（调试串口路径） | 出厂默认信道计划与现款一致（EU868 三频点 + RX2；US915 现行子带与信道掩码）；经调试串口配置频点 / 启用信道集 / 子带：写入 → 读回 → 断电重启后保持 100% 一致；区域标准计划外的取值全部拒绝并记录；配置为单频点后入网与上下行收发正常；**全频道集启用验证（EU868 / US915 范围）**：启用区域计划完整频道集（EU868 全 8 信道含 CFList 扩展信道；US915 全部子带与信道掩码配置）后入网与各频道收发正常；网关 / 网络服务器侧信道计划同步配置流程写入交付文档并实测一遍。CN470 等其余频段的全频道验证随订单 / 二期执行 |
| C-07 | 单频点与多频点入网时延对比（频点方案折中的直接验证） | 同环境同批设备，默认多频点计划与单频点配置各完成 ≥30 次冷启动入网，记录 P50 / P95 入网完成时间；单频点模式不劣于多频点模式；数据随测试报告交付 |
| C-08 | 批量上电入网（≥10 台同时上电） | 两组对比：全部默认计划同批上电，与各设备分散指配单频点上电；记录整批入网完成时间与失败数，分散指配组不得出现因信道占用导致的入网失败放大；产出部署建议（默认计划 / 分散指配 / 单点收敛的适用场景） |
| C-09 | LoRa 参数远程配置（LoRaWAN 下行路径，主线款与蓝牙款均执行） | 平台经 LoRaWAN 下发远程配置指令：ADR 开关 / 入网方式 / 速率 / 频点 / 启用信道集各类各 ≥10 次，写读回与断电保持 100% 一致；非法取值 100% 拒绝并应答错误码；配置后设备按新参数重新入网与收发正常（涉及网关 / NS 侧信道计划的按交付文档同步后验证）；远程配置与 C-06 串口路径写入结果一致 |

### P 下行实时性集（P-01 ~ P-03）

| 用例 | 测试项 | 判定标准 |
|---|---|---|
| P-01 | 纯 Class C 下行时延 | 10 台级联下平台下发通断 → 空开应答，重复 50 次取 P95，不劣于现款基线 120% |

### 基线建档

对现款利尔达固定频率模组设备同环境实测 P-01/P-02 下行时延、C-01 入网成功率、C-02 退避时序、C-05 弱场极限，形成对比基线（首产品 M1 执行）；新固件全部对比判定以此为锚。蓝牙状态 / 控制 / OTA 为新增能力，采用绝对指标，不参与现款基线对比。
