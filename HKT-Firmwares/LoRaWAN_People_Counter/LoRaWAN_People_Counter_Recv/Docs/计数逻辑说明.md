# LoRaWAN 红外计数器计数逻辑说明

## 1. 人员通过计数时序图

### 1.1 A->B 方向通过（最终计入 B）

```mermaid
sequenceDiagram
    participant A as 红外A中断
    participant B as 红外B中断
    participant H as People_Counter_Handle(10ms)
    participant C as 计数器变量
    participant U as updateCounter

    Note over A,B: 场景1：A->B 方向通过
    A->>H: counter_a_sense_count 增长(先触发)
    H->>H: step1=2 (先A后B路径)
    B->>H: counter_b_sense_count 增长(后触发)
    H->>H: step2=2
    H->>H: 等待A/B都>4(恢复双通)
    H->>C: counter_a_value++ / counter_a_count++
    H->>C: direction = PASSAGE_DIRECTION_B_TO_A
    H->>H: countDelay=20(约200ms)
    H->>U: 按reportMode决定是否置1
```

### 1.2 B->A 方向通过（最终计入 A）

```mermaid
sequenceDiagram
    participant A as 红外A中断

    participant H as People_Counter_Handle(10ms)

    Note over A,B: 场景2：B->A 方向通过
    B->>H: counter_b_sense_count 增长(先触发)

    A->>H: counter_a_sense_count 增长(后触发)

    H->>U: 按reportMode决定是否置1
```

## 2. 模式与计数状态机

```mermaid
stateDiagram-v2
    [*] --> ALIGNMENT_MODE
    ALIGNMENT_MODE --> VALIDATION_MODE: mode_timeout到期(1分钟)
    VALIDATION_MODE --> COUNTING_MODE: mode_timeout到期(2分钟)
    COUNTING_MODE --> COUNTING_MODE: 持续运行

    state COUNTING_MODE {
      [*] --> IDLE
      IDLE --> STEP1_AB: A弱/B强(先B触发路径)
      IDLE --> STEP1_BA: B弱/A强(先A触发路径)

      STEP1_AB --> STEP2_AB: 出现B弱/A强
      STEP1_BA --> STEP2_BA: 出现A弱/B强

      STEP2_AB --> COMMIT_B: A/B都>4(恢复双通)
      STEP2_BA --> COMMIT_A: A/B都>4(恢复双通)

      COMMIT_B --> IDLE: counter_b++，延时抑制
      COMMIT_A --> IDLE: counter_a++，延时抑制
    }
```

## 3. 上报触发流程图

```mermaid
flowchart TD
    A[发生有效计数] --> B{COUNTING_MODE?}
    B -- 否 --> Z[不置updateCounter]
    B -- 是 --> C{reportMode判定}
    C -->|计数变化模式| D[updateCounter=1]
    C -->|阈值模式且A+B>=reportTotalCount| D
    C -->|周期模式到时| D
    D --> E[DeviceStateProcess检测到]
    E --> F[Device_IRCountReport上报]
    F --> G[打包A/B增量+A/B总量]
    G --> H[发送成功后清零counter_a_value/counter_b_value]
```

## 4. 服务器下发“清零并上报”命令时序图

```mermaid
sequenceDiagram
    participant S as 服务器
    participant L as LoRa模组/串口接收
    participant P as fromLoRaWANDataHandle
    participant D as device_t计数变量
    participant M as DeviceStateProcess
    participant R as Device_IRCountReport

    S->>L: 下发 DATATYPE_DEVICE_IR_REPORT_COUNT(dataTypeReport=1)
    L->>P: 进入命令解析
    P->>D: counter_a_value=0
    P->>D: counter_b_value=0
    P->>D: counter_a_count=0
    P->>D: counter_b_count=0
    P->>D: updateCounter=1
    Note over P,D: 先清零，再置位上报标志
    M->>R: 检测到updateCounter后触发上报
    R->>L: 打包并发送 DATATYPE_DEVICE_IR_REPORT_COUNT
    L-->>S: 上报清零后的计数结果(通常为0)
```

## 5. 关键代码位置

- 计数状态机：`USER/Drive/control_center.c` 的 `People_Counter_Handle()`
- 传感器脉冲来源：`USER/Drive/gpio.c` 的 `EXTI4_15_IRQHandler()`
- 周期计时与1ms调度：`USER/Drive/systick.c` 的 `Systick_1ms_Handler()`
- 上报触发与发送：`USER/Drive/communicate.c` 的 `DeviceStateProcess()`、`Device_IRCountReport()`
- 服务器命令解析与清零：`USER/Drive/communicate.c` 的 `fromLoRaWANDataHandle()`
