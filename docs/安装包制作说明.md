## 快速构建

### Debug 版本（测试用）

```bash
gradlew.bat assembleDebug
```

**输出路径：**
```
app/build/outputs/apk/debug/app-debug.apk
```

**特点：**
- 无需签名配置
- 包含调试信息
- 可直接安装到设备

---

### Release 版本（发布用）

```bash
gradlew.bat assembleRelease
```

**输出路径：**
```
app/build/outputs/apk/release/app-release-unsigned.apk
```

> ⚠️ **注意**：当前配置未启用签名，生成的 APK 为未签名版本。如需发布，请按下方说明配置签名。

## Release 签名配置

### 1. 准备签名密钥

项目根目录已有签名密钥库 `key.jks`。如需创建新密钥库：

```bash
keytool -genkey -v -keystore key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias hkt
```

### 2. 配置签名信息

在 `local.properties` 文件中添加（位于项目根目录）：

```properties
storePassword=你的密钥库密码
keyPassword=你的密钥密码
keyAlias=hkt
storeFile=../key.jks
```

### 3. 修改构建配置

在 `app/build.gradle.kts` 中添加签名配置：

```kotlin
android {
    // ... 其他配置

    signingConfigs {
        create("release") {
            storeFile = file("../key.jks")
            storePassword = System.getenv("KEYSTORE_PASSWORD")
                ?: findProperty("signing.storePassword") as String?
            keyAlias = System.getenv("KEY_ALIAS")
                ?: findProperty("signing.keyAlias") as String?
            keyPassword = System.getenv("KEY_PASSWORD")
                ?: findProperty("signing.keyPassword") as String?
        }
    }

    buildTypes {
        release {
            isMinifyEnabled = false
            signingConfig = signingConfigs.getByName("release")
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}
```

### 4. 构建签名版本

```bash
gradlew.bat assembleRelease
```

**输出路径：**
```
app/build/outputs/apk/release/app-release.apk
```

## 版本号管理

版本信息位于 `app/build.gradle.kts`：

```kotlin
defaultConfig {
    versionCode = 1      // 整数，用于版本比较
    versionName = "2.0"  // 字符串，显示给用户
}
```

### 版本更新规则

- **versionCode**: 每次发布递增 1
- **versionName**: 根据变更程度更新
  - 主版本：重大功能变更
  - 次版本：功能增加
  - 修订号：Bug 修复

## 常见问题

### 1. Gradle 构建失败

**原因**：Gradle Wrapper 未正确下载

**解决**：
```bash
gradlew.bat --version
```

如果失败，检查网络连接或配置代理。

### 2. SDK 未找到

**错误信息**：`SDK location not found`

**解决**：
创建 `local.properties` 文件：
```properties
sdk.dir=C:\\Users\\用户名\\AppData\\Local\\Android\\Sdk
```

### 3. 签名失败

**错误信息**：`Keystore file not found`

**解决**：
确认 `key.jks` 文件位于项目根目录，路径配置正确。

### 4. 安装失败 - INSTALL_FAILED_UPDATE_INCOMPATIBLE

**原因**：设备上已安装签名不同的同包名应用

**解决**：
先卸载旧版本：
```bash
adb uninstall com.hkt.ble.tools
```

## APK 验证命令

### 查看签名信息

```bash
# 使用 apksigner (推荐)
apksigner verify -v --print-certs app/build/outputs/apk/release/app-release.apk

# 使用 keytool
keytool -printcert -jarfile app/build/outputs/apk/release/app-release.apk
```

### 查看 APK 信息

```bash
# 使用 aapt
aapt dump badging app/build/outputs/apk/release/app-release.apk
```
