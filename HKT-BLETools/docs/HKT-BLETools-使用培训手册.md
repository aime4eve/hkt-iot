# HKT BLETools 使用培训手册

| 项目 | 内容 |
| --- | --- |
| 适用版本 | BLETools v3.17 及之后界面一致的版本 |
| 文档日期 | 2026-09-02 |
| 适用人员 | 现场实施、售后技术支持、测试和产线调试人员 |
| 设备范围 | UDS100、DC200/EPS100/MPS100、SVC100 |
| 界面语言 | 当前版本启动后固定为英文；本手册用中文解释英文界面 |

## 1. 培训目标

完成本培训后，学员应能独立完成：

1. 检查手机权限、蓝牙和设备电源。
2. 使用扫码、手工输入 DevEUI 或普通扫描连接设备。
3. 阅读 Status 页，判断设备是否在线和状态是否正常。
4. 按设备类型修改参数并使用 `Save Settings` 下发。
5. 对 SVC100 配置实时任务、定时任务和删除任务。
6. 执行校准、时间同步、开关机和 OTA 升级。
7. 按排障流程定位“扫不到、连不上、配置失败、OTA 失败”等常见问题。

## 2. 准备工作

### 2.1 手机要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 8.0 或以上 |
| 硬件 | 手机必须支持 BLE |
| 蓝牙 | 已开启 |
| 网络 | 常规配置和 OTA 不依赖服务器；下载 APK 或固件时才需要网络 |
| 其他 | 建议关闭会长期抢占 BLE 的后台应用 |

### 2.2 必须确认的权限

首次启动 App 时会申请以下权限：

| 权限 | 用途 | 是否建议允许 |
| --- | --- | --- |
| Nearby devices / Bluetooth Scan、Connect | 扫描和连接 BLE 设备 | 必须允许 |
| Location / Fine Location | 旧 Android 版本扫描 BLE 需要 | 必须允许 |
| Camera | 扫描二维码 / 条码 | 使用扫码连接时必须允许 |
| All files access | 读取 OTA 固件文件和保存诊断日志 | 建议允许；拒绝后 OTA 可能受限 |

> 提示：如果权限被拒绝，可进入系统 `Settings` > `Apps` > `BLETools` > `Permissions` 重新开启。

### 2.3 设备侧检查

1. 确认设备型号：UDS100、DC200/EPS100/MPS100 或 SVC100。
2. 确认设备已上电，电量或外部电源满足现场要求。
3. 确认设备广播名称可识别；普通扫描时可打开无名设备开关。
4. 同一时间只配置一台设备，避免多人在同一区域同时操作。
5. 升级、校准或修改阀门任务前，确认现场具备安全条件。

## 3. 安装与首次启动

### 3.1 安装 APK

1. 将正式提供的 APK 复制到手机，建议使用 `app-prod-debug.apk` 这类可安装包。
2. 在手机文件管理器中点击 APK。
3. 首次安装时，按系统提示允许“安装未知应用”。
4. 安装完成后打开 `BLETools`。

> 注意：不要在同一台手机上混装 `prod` 和 `dev` 变体用于现场交付。`dev` 变体的包名会追加 `.dev`，仅用于开发测试。

### 3.2 首次启动检查

1. 允许蓝牙和定位相关权限。
2. 系统提示开启蓝牙时，点击允许开启。
3. 确认 App 没有提示 `Bluetooth not supported`。
4. 点击右上角 `About` 查看版本，确认现场使用的是预期版本。

## 4. 主界面与连接设备

### 4.1 主界面入口

| 界面入口 | 功能 |
| --- | --- |
| `Scan` 图标 | 开始或停止 BLE 扫描 |
| 扫码图标 | 打开摄像头扫描二维码 / 条码 |
| `Input EUI` | 手工输入 16 位十六进制 DevEUI |
| `Filter` | 设置 RSSI 过滤值，控制是否显示无名设备 |
| `About` | 查看版本和诊断日志 |

### 4.2 方式一：扫码连接

适用场景：设备标签上有 16 位 DevEUI 二维码或条码。

1. 点击主界面扫码图标。
2. 允许相机权限。
3. 对准设备标签上的二维码 / 条码。
4. App 读取到合法的 16 位十六进制 DevEUI 后，会按 EUI 后 6 位进行目标扫描。
5. 找到目标后点击设备，等待连接成功。

### 4.3 方式二：手工输入 DevEUI

适用场景：二维码损坏，但纸质标签上有完整 DevEUI。

1. 点击右上角菜单 `Input EUI`。
2. 输入框会预填默认前缀 `0095690`。
3. 补全为 16 位十六进制字符，可使用 `0-9`、`A-F`、`a-f`。
4. 点击 `Connect` 或键盘上的完成键。
5. App 使用 DevEUI 后 6 位匹配目标设备。
6. 找到后点击设备进行连接。

### 4.4 方式三：普通扫描

适用场景：现场设备数量少，或无法读取 DevEUI。

1. 点击右上角 `Scan` 图标。
2. App 会连续执行 3 轮扫描，每轮约 10 秒。
3. 在列表中根据设备名称、Mac 地址和 RSSI 选择目标设备。
4. 点击设备，等待连接结果。

### 4.5 扫描过滤

1. 点击右上角菜单 `Filter`。
2. 调整 `RSSI` 滑块：
   - `-100 dBm`：保留更多弱信号设备。
   - `-40 dBm`：只保留非常靠近手机的强信号设备。
3. 打开 `Filter devices without names` 开关后，可显示无广播名称的设备。
4. 点击 `Close` 关闭弹窗。

> 现场建议：如果周围 BLE 设备很多，先把手机靠近目标设备，再将 RSSI 阈值调到 `-60 dBm` 或更强，减少误连风险。

### 4.6 连接成功判断

连接成功后会出现：

1. `Bluetooth connection successfully` 提示。
2. App 自动进入设备详情页。
3. 详情页顶部出现 `Status` 分组。
4. 短暂同步后出现 `Sync successfully`。

如果超过约 15 秒仍无连接结果，会出现 `Bluetooth connection failed`。请返回后重试。

## 5. 设备详情页通用操作

设备详情页使用折叠分组。不同设备显示的分组数量不同，但界面标题多数为 `Status` 和 `Config`，需要按展开顺序判断功能。

### 5.1 分组顺序

| 设备 | 分组顺序 |
| --- | --- |
| UDS100 | `Status`、`Power`、`Calibration`、参数配置、`Timestamp`、`OTA` |
| DC200/EPS100/MPS100 | `Status`、`Power`、`Calibration`、参数配置、`Timestamp`、`OTA` |
| SVC100 | `Status`、`Power`、参数配置、实时任务、定时任务、`Timestamp`、`OTA` |

### 5.2 Status 状态页

`Status` 展开后显示设备当前值，通常包括：

| 设备 | 常见状态项 |
| --- | --- |
| UDS100 | Name、Version、Power、Battery、Temperature、Humidity、Distance、Overflow State、Low/High Threshold、Latitude、Longitude、Report Period、Gps Period |
| DC200/EPS100/MPS100 | Name、Version、Power、Battery、Parking Status、Tamper Status、Report Period、Mag X/Y/Z、Radar Spectrum |
| SVC100 | Name、Version、Power、Battery、Port1/Port2 状态、脉冲数、输出电压、端口功能、稳定时间、时区、上报周期 |

> 重要：展开或点击 `Status` 时，App 会把未提交的配置值重置为设备当前值。开始修改配置前，建议先打开 `Status` 同步一次，避免把旧输入误发给设备。

### 5.3 Power 电源开关

1. 展开 `Power` 分组。
2. 使用右侧开关切换 `ON` / `OFF`。
3. 等待弹窗关闭并出现 `Executed successfully`。
4. 返回 `Status` 确认 `Power` 已更新。

> 注意：不要在校准、任务下发或 OTA 过程中切换电源。

### 5.4 Calibration 校准

适用设备：DC200/EPS100/MPS100 等地磁 / 雷达车位传感器；其他设备是否执行校准以固件规格为准。

1. 确认 `Status` 中设备 `Power` 为 `ON`。
2. 展开 `Calibration`。
3. 点击 `execute`。
4. App 提示校准约需 90 秒；实际现场等待不要离开设备。
5. 等待 `Executed successfully`。
6. 将车辆按现场规范停入车位或移开车辆，观察 `Parking Status` 是否更新。

> DC200/EPS100/MPS100 的校准等待时间可放宽到 3 分钟。等待期间不要关闭蓝牙、锁屏过久或切换页面。

### 5.5 Save Settings 保存规则

`Save Settings` 表示保存并下发当前面板内的全部相关参数，而不是只保存某一个字段。

通用流程：

1. 展开 `Status`，让 App 读取当前值。
2. 展开对应 `Config`。
3. 修改需要变更的字段。
4. 点击 `Save Settings`。
5. 等待 `Executed successfully`。
6. 展开 `Status` 复核设备回读值。

如果输入非法，App 会在对应输入框显示错误，并阻止发送配置命令。

## 6. UDS100 配置

UDS100 是超声波垃圾桶满溢监测传感器。

### 6.1 参数和允许范围

| 界面项 | 允许值 | 说明 |
| --- | --- | --- |
| `Low Threshold (mm)` | `30-4500` | 低阈值，单位毫米 |
| `High Threshold (mm)` | `0` 或 `30-4500` | `0` 表示不判断高阈值 |
| `Report Period (min)` | `1-1440` | 状态周期上报间隔，单位分钟 |
| `GPS Period (min)` | `0` 或 `10-1440` | `0` 表示不进行 GPS 定位 |

### 6.2 配置步骤

1. 展开 `Status`，确认设备在线且当前值已回读。
2. 展开参数配置分组。
3. 输入新的低阈值、高阈值、上报周期和 GPS 周期。
4. 点击 `Save Settings`。
5. 等待成功提示。
6. 展开 `Status` 检查 `Low Threshold`、`High Threshold`、`Report Period`、`Gps Period`。

### 6.3 状态解释

| Overflow State 值 | 含义 | 处理建议 |
| --- | --- | --- |
| `Normal` | 距离在阈值区间内 | 正常 |
| `Low threshold triggered` | 距离低于低阈值 | 现场按满溢 / 接近规则处理 |
| `High threshold triggered` | 距离高于高阈值 | 检查安装高度、空桶状态或高阈值配置 |
| `Invalid` | 距离测量无效 | 检查传感器遮挡、安装位置和距离范围 |

## 7. DC200 / EPS100 / MPS100 配置

DC200、EPS100 和 MPS100 在 App 中使用同一套车位传感器配置界面。

### 7.1 检测模式

| Detection Mode 选项 | 固件值 | 说明 |
| --- | --- | --- |
| `Magnetic + Radar` | `0` | 地磁和雷达融合检测 |
| `Magnetic Only` | `1` | 仅使用磁力计检测 |
| `Radar Priority` | `2` | 雷达优先；被覆盖时回退地磁判断 |

### 7.2 参数配置

| 界面项 | 允许值 | 说明 |
| --- | --- | --- |
| `Detection Mode` | 三选一 | 按车位类型和现场干扰选择 |
| `Report Period (min)` | `1-1440` | 上报周期，单位分钟 |

### 7.3 配置步骤

1. 展开 `Status`，确认 `Power`、`Parking Status` 和当前模式可读。
2. 展开参数配置分组。
3. 选择 `Detection Mode`。
4. 输入新的 `Report Period (min)`。
5. 点击 `Save Settings`。
6. 等待 `Executed successfully`。
7. 展开 `Status` 确认模式和上报周期。

### 7.4 车位状态

| Parking Status | 含义 | 处理建议 |
| --- | --- | --- |
| `Vacant` | 无车 | 正常空位 |
| `Occupied` | 有车 | 正常占用 |
| `Covered` | 异常或被覆盖 | 检查是否有水膜、异物、金属遮挡或安装问题 |
| `Unknown` | 协议返回未知值 | 抓取 Debug / 日志并联系研发 |

> 修改模式后，建议现场至少完成一次停车和离位测试。

## 8. SVC100 配置

SVC100 是双路电磁阀控制器，配置项较多，操作前必须确认阀门和现场执行机构安全。

### 8.1 通用参数

| 界面项 | 选项 / 范围 | 说明 |
| --- | --- | --- |
| `Output Voltage` | `12V / 9V / 5V` | 输出电压等级 |
| `Port Function` | 见下表 | 配置端口 1、端口 2 的脉冲或开关状态模式 |
| `Stable Time (s)` | `1-255` | 只在带 stable time 的端口功能下生效；其他模式下 App 会禁用输入 |
| `Power Mode` | `Manual power on/off` / `Automatic power on/off` | 手动或自动开关机 |
| `Timezone` | `UTC-12:00` 到 `UTC+12:00`，另含 `UTC+03:30`、`UTC+05:30` | 用于设备本地时间相关任务 |
| `Report Period (min)` | `0` 或 `1-1440` | `0` 表示设备侧不按周期上报；正式现场不建议随意配置为 `0` |

### 8.2 端口功能解释

| Port Function | 协议值 | 含义 |
| --- | --- | --- |
| `Port 1 + Port 2 pulse` | `0x00` | 两个端口均为脉冲模式 |
| `Port 1 switch, Port 2 pulse` | `0x01` | 端口 1 开关状态，端口 2 脉冲 |
| `Port 1 pulse, Port 2 switch` | `0x02` | 端口 1 脉冲，端口 2 开关状态 |
| `Port 1 + Port 2 switch` | `0x03` | 两个端口均为开关状态 |
| `Port 1 switch, Port 2 pulse (stable time)` | `0x81` | 端口 1 开关状态并使用稳定时间，端口 2 脉冲 |
| `Port 1 pulse, Port 2 switch (stable time)` | `0x82` | 端口 1 脉冲，端口 2 开关状态并使用稳定时间 |
| `Port 1 + Port 2 switch (stable time)` | `0x83` | 两个端口均为开关状态并使用稳定时间 |

配置步骤：

1. 展开 `Status`，确认两个端口当前状态。
2. 展开 SVC 参数配置分组。
3. 选择 `Output Voltage`。
4. 选择 `Port Function`。
5. 如果选择了带 `stable time` 的模式，设置 `Stable Time (s)`；否则保持原值即可。
6. 选择 `Power Mode`、`Timezone` 和 `Report Period (min)`。
7. 点击 `Save Settings`。
8. 等待成功提示后回读 `Status`。

### 8.3 Real-time Task 实时任务

实时任务用于立即驱动阀门动作。

| 界面项 | 选项 / 范围 | 说明 |
| --- | --- | --- |
| `Valve` | `1&2`、`1`、`2` | 对应双阀、阀 1、阀 2 |
| `State` | `Close` / `Open` | 初始执行方向 |
| `Time (s)` | `0-65535` | 持续时间，单位秒；`0` 表示不按时间结束 |
| `Pulse` | `0-65535` | 达到脉冲数后结束任务 |

配置步骤：

1. 展开实时任务分组。
2. 选择阀门。
3. 选择 `Close` 或 `Open`。
4. 输入持续时间或脉冲数。
5. 点击 `Save Settings`。
6. 观察阀门实际动作和 App 成功提示。

> 安全提醒：实时任务会立即控制阀门。操作前必须确认现场水路、气路、管路和人员安全。

### 8.4 Timed Task 定时任务

定时任务保存在设备本地，由设备按本地时间执行。

| 界面项 | 选项 / 范围 | 说明 |
| --- | --- | --- |
| `Task` | `1-16` | 保存任务使用 `1-16` |
| `Valve` | `1&2`、`1`、`2` | 对应双阀、阀 1、阀 2 |
| `State` | `Close` / `Open` | 任务执行方向 |
| `Pulse` | `0-65535` | 脉冲数 |
| `Time Range` | 当天 `00:00-23:59` | 结束时间必须晚于开始时间 |
| `Repeat` | `1-7` | 按星期重复；`bit0-bit6` 对应第 1 到第 7 天 |

配置步骤：

1. 先确认设备时区或本地时间正确。
2. 展开定时任务分组。
3. 在 `Task` 中选择 `1-16`。不要选择 `FF`；`FF` 仅用于全部删除场景。
4. 选择阀门和状态。
5. 输入脉冲数。
6. 点击开始时间和结束时间输入框，使用时间选择器设置范围。
7. 点击 `Repeat`，勾选需要执行的日期。
8. 点击 `Save Settings`。
9. 等待成功提示，并在对应时间观察设备是否执行。

### 8.5 删除定时任务

| 操作 | 结果 |
| --- | --- |
| 选择 `1-16` 后点击 `Delete` | 删除指定任务 |
| 选择 `FF` 后点击 `Delete` | 清除全部定时任务 |

> 删除全部任务前，必须确认现场没有仍需保留的本地任务。

## 9. 时间同步

1. 展开 `Timestamp` 分组。
2. 确认界面显示的是当前手机时间。
3. 点击同步按钮。
4. 等待 `Executed successfully`。
5. 对 SVC100，配置定时任务前建议先完成时间同步。

> 如果设备本地时间不准，定时任务可能提前、延后或不触发。SVC100 还必须确认时区配置正确。

## 10. OTA 固件升级

### 10.1 升级前检查

1. 使用设备对应的官方固件文件。
2. 确认固件型号、硬件版本和地区版本匹配。
3. 确认手机电量充足，建议大于 50%。
4. 确认设备供电稳定；电池设备建议连接外部电源或满电后操作。
5. 保持手机在设备旁边，不要锁屏后长时间离开。
6. 升级期间不要退出设备详情页、关闭蓝牙或连接其他设备。

### 10.2 升级步骤

1. 展开设备详情页中的 `OTA` 分组。
2. 点击 `Select File`。
3. 在系统文件选择器中选择官方 `.bin` 固件。
4. 确认界面显示的文件名和文件大小正确。
5. 点击升级按钮。
6. 保持 App 前台，等待进度条完成。
7. 看到 `OTA Successful` 后等待设备重启。
8. 重新连接设备，展开 `Status` 检查 `Version`。

### 10.3 升级失败处理

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示选择固件文件 | 未选择文件或文件读取失败 | 重新选择正确 `.bin` 文件 |
| 提示文件读取失败 | 权限不足、文件损坏或文件服务不可用 | 开启所有文件访问权限，重新拷贝固件文件 |
| 长时间无进度 | BLE 断开、设备掉电或手机休眠 | 保持靠近、充电、亮屏后重试 |
| 升级后无法连接 | 固件启动异常或升级不完整 | 按设备说明重新上电；仍失败时联系研发 |

## 11. Debug、About 和日志

### 11.1 About

1. 主界面点击右上角 `About`。
2. 查看版本号。
3. 查看最近诊断日志。
4. 反馈问题时截图或导出日志。

### 11.2 Debug

1. 进入设备详情页。
2. 点击右上角 `Debug` 菜单。
3. 查看原始 BLE 通信数据。
4. 反馈协议问题时记录时间点、发送方向和相关命令。

> Debug 数据用于研发排查，现场不要随意转发到外部群组，避免泄露设备 EUI 或现场信息。

## 12. 推荐现场操作顺序

1. 开启手机蓝牙，打开 App，确认权限。
2. 扫码、输入 EUI 或扫描连接设备。
3. 打开 `Status`，确认设备名称、版本、电量和状态。
4. 如需要，先执行时间同步。
5. 修改参数并点击 `Save Settings`。
6. 回到 `Status` 回读确认。
7. 现场触发状态或任务，验证业务行为。
8. 记录设备编号、修改前后参数、时间和操作人。
9. 如需升级，最后执行 OTA，并再次回读版本。
10. 正常退出设备详情页，关闭设备或恢复现场运行状态。

## 13. 常见问题排查

| 问题 | 可能原因 | 处理步骤 |
| --- | --- | --- |
| 扫不到设备 | 设备未上电、距离太远、广播无名、权限缺失 | 确认上电；靠近设备；打开无名设备显示；检查蓝牙和定位权限 |
| 目标扫描找不到 | DevEUI 输入错误或实际广播后缀不匹配 | 核对 16 位 DevEUI；改用普通扫描确认广播名 |
| 蓝牙连接失败 | 设备被其他手机占用、信号弱、设备忙 | 关闭其他连接；靠近设备；重试；必要时设备重新上电 |
| 详情页一直同步 | BLE 未完全连接或状态轮询异常 | 返回重连；查看手机蓝牙；抓取日志 |
| `Save Settings` 无成功提示 | 输入非法、BLE 断开或设备未 ACK | 检查红色输入框；返回确认连接；重试 |
| 配置成功但状态未变化 | 设备需要时间刷新或现场条件未触发 | 展开状态刷新；等待一个采集周期；触发现场动作测试 |
| MPS100 状态显示 `Covered` | 雷达被水膜、异物或特殊遮挡覆盖 | 清洁或检查安装环境，确认安装高度和角度 |
| SVC100 定时任务不执行 | 本地时间或时区错误、星期未勾选、任务号错误 | 同步时间；确认时区；检查 Repeat 和任务内容 |
| OTA 选择文件失败 | 权限不足或文件不可读 | 开启所有文件访问权限；使用本地存储中的官方固件 |
| App 提示断开 | 距离过远、设备休眠、电源不稳 | 靠近设备；确认供电；重新连接 |

## 14. 安全与交付注意事项

1. 修改 SVC100 阀门、任务或电源模式前，确认现场执行机构允许动作。
2. 修改上报周期会影响平台数据频率，避免设置过短导致网络和功耗压力。
3. 校准、升级和删除全部任务属于影响性操作，操作前必须记录当前参数。
4. 现场交付建议保存以下信息：
   - 设备型号和 DevEUI；
   - 修改前后的参数；
   - App 版本和固件版本；
   - 操作时间、操作人和现场结果。
5. 反馈问题时至少提供：设备型号、DevEUI、App 版本、固件版本、操作步骤、预期结果、实际结果、Debug 截图和日志。
