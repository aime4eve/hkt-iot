# HKT BLETools 蓝牙工具功能介绍

| 项目 | 内容 |
| --- | --- |
| 适用对象 | 内部开发与维护人员 |
| 文档范围 | 当前 APK 已具备的功能与操作方式；不展开 BLE 协议实现、代码架构和维护风险 |
| 代码基线 | `versionName 3.16`，`versionCode 20260820` |
| 主要入口 | Android App `MainActivity` -> `DeviceActivity` |

## 1. 工具定位

HKT BLETools 是 HKT 系列 BLE IoT 设备的 Android 本机配套工具，用于在设备旁完成发现、连接、状态查看、参数配置、任务配置、校准、时间同步和固件升级。工具不依赖云端业务系统，核心操作通过手机与设备之间的 BLE GATT 连接完成。

当前代码按广播名称识别以下设备：

| 设备 | 用途 | 广播名称匹配规则 |
| --- | --- | --- |
| UDS100 | 超声波垃圾桶满溢监测传感器 | 名称包含 `UDS100` |
| DC200 系列 | 地磁/雷达车位传感器 | 名称包含 `DC200`、`EPS100` 或 `MPS100`，App 内统一按 DC200 功能处理 |
| SVC100 | 双电磁阀/端口控制器 | 名称包含 `SVC100` |

App 是单连接模型：同一时间只维护一个目标设备的 GATT 连接和配置页面。

## 2. 使用前提

1. 手机要求 Android 8.0（API 26）及以上，并支持 BLE。
2. 首次使用需要授予蓝牙、定位、相机等权限；Android 12 及以上会申请附近设备权限。
3. Android 11 及以上会提示“所有文件访问”权限，主要用于运行日志和崩溃日志落盘。拒绝该权限不会阻断蓝牙主流程，但公共 Download 目录日志可能不可用。
4. BLE 扫描、GATT 连接、配置、校准和 OTA 必须使用真机和真实设备验证。模拟器没有真实蓝牙硬件，只能检查界面、启动和权限流程。
5. 设备应处于可广播、可连接状态，并尽量靠近手机，避免弱信号导致连接或指令超时。

## 3. 首页功能：扫描与连接

### 3.1 常规扫描

入口：首页右上角蓝牙图标（菜单标题为 `Scan`）。

操作步骤：

1. 打开 App，确认手机蓝牙已开启。
2. 点击右上角蓝牙图标开始扫描。
3. 扫描列表按 MAC 地址去重，同一个设备重复广播时只保留一项，并刷新 RSSI。
4. 点击目标设备行发起连接。
5. 连接成功后自动进入设备页；连接失败会在约 15 秒后提示 `Bluetooth connection failed`。

扫描行为：

- 使用低延迟扫描模式。
- 每次 10 秒，共 3 轮，轮间暂停 500 毫秒。
- 三轮结束后自动停止，并提示 `Scan complete (3 cycles)`。
- 扫描过程中再次点击蓝牙图标可手动停止。
- 列表每行显示设备名称、MAC 地址和当前 RSSI。

### 3.2 扫描过滤

入口：首页右上角溢出菜单 `Filter`。

可配置项：

| 配置 | 操作 | 效果 |
| --- | --- | --- |
| `RSSI` | 拖动滑杆，范围约 `-40 dBm` 到 `-100 dBm` | 低于阈值的广播不会进入列表；已有列表会立即按阈值过滤 |
| `Filter devices without names` | 打开或关闭开关 | 打开后过滤无名称广播；关闭后无名称设备以 `N/A` 显示 |

RSSI 阈值会保存到本机配置，下次进入 App 继续生效。若现场广播设备很多，可先提高 RSSI 阈值减少干扰。

### 3.3 扫码连接

入口：首页右上角相机图标（菜单标题为 `Scan`）。

操作步骤：

1. 点击相机图标进入条码/二维码扫描页。
2. 扫描内容必须是 16 位十六进制 DevEUI，大小写均可。
3. 扫描成功后 App 取 DevEUI 最后 6 位并转为大写，作为目标匹配后缀。
4. App 自动开始定向 BLE 扫描；发现广播名称包含该后缀的设备后自动连接。
5. 三轮扫描后仍未找到目标时，提示 `Target device not found`。

扫码页支持返回或取消。扫描结果不是合法 DevEUI 时，App 会提示 `Error: <扫描内容>`，不会发起连接。

### 3.4 手工录入 DevEUI

入口：首页右上角溢出菜单 `Input EUI`。

操作步骤：

1. 选择 `Input EUI`。
2. 输入 16 位十六进制 DevEUI；输入框默认预填前缀 `0095690`。
3. 点击 `Connect`。
4. App 使用该 DevEUI 最后 6 位发起定向扫描，命中后自动连接。

输入不合法时会提示 `Enter a 16-character hexadecimal DevEUI`，对话框保持打开，便于直接修改。

## 4. 设备页通用功能

连接成功后进入设备页。页面由可展开分组组成：`Status` 用于查看设备状态，其余 `Config` 分组按设备类型提供电源、校准、参数、任务、时间同步和 OTA 功能。

### 4.1 状态查看

设备页每秒刷新界面展示数据，连接正常时后台约每秒查询一次设备状态。点击展开 `Status` 可查看当前值。

| 设备 | 状态字段 |
| --- | --- |
| UDS100 | Name、Version、Power、Battery、Temperature、Humidity、Alarm Status、Angle、Slant、Distance、Overflow State、Low/High Threshold、Latitude、Longitude、Report Period、Gps Period |
| DC200 系列 | Name、Version、Power、Battery、Parking Status、Tamper Status、Report Period、Mag X/Y/Z、Radar Spectrum |
| SVC100 | Name、Version、Power、Battery、Port1/Port2 value state、Port1/Port2 insert state、Port1/Port2 pulse count、Voltage out level、Interface function、Buffeting duration、Timezone、Report Period |

点击 `Status` 分组标题会把待配置参数重置为设备当前值，并刷新配置表单。现场操作前建议先点一次 `Status`，确认表单值来自设备而不是上一次遗留输入。

### 4.2 数值输入

所有受控数值字段在列表中为只读展示。点击字段后弹出独立数字输入窗口，输入符合范围后点击 `OK` 写回表单，再点击对应配置按钮下发。

常见反馈：

- 参数合法且设备确认：提示 `Executed successfully`，状态和表单随后刷新。
- 输入越界或格式错误：提示 `The input format is incorrect` 或 `Enter a valid number for this field`，不会下发。
- 设备长时间未确认：提示 `timeout`。

### 4.3 电源控制

入口：设备页 `Power` 配置项。

操作：切换 `Power` 开关。

- 打开为 `ON`，下发开机/上电指令。
- 关闭为 `OFF`，下发关机/下电指令。
- 指令等待期间显示处理中遮罩，成功后提示 `Executed successfully`。

开关状态会随设备状态回报更新。如果状态同步导致开关显示变化，App 不会把它当作用户操作再次下发指令。

### 4.4 校准

入口：UDS100 和 DC200 系列设备页的 `Calibration` 配置项；SVC100 不显示校准功能。

操作步骤：

1. 确认 `Status` 中 Power 为 `ON`。
2. 展开 `Calibration`，点击 `execute`。
3. 保持手机与设备靠近且不要断开连接，等待校准完成。

App 会提示校准预计约 90 秒。等待上限按设备区分：DC200/EPS100/MPS100 为 3 分钟，其他非 SVC100 校准路径为 2 分钟。设备 Power 为 `OFF` 时点击会提示 `Calibration Error, Result Power OFF`，不会执行。

### 4.5 时间戳同步

入口：设备页 `Timestamp` 配置项。

页面显示手机当前 Unix 时间戳，单位为秒，并每秒刷新。点击 `Sync` 会把当前显示的时间戳下发到设备，成功后提示 `Executed successfully`。

当前代码基线中，UDS100、DC200 系列和 SVC100 的设备页都会渲染该功能；是否适合某批固件使用，需结合现场设备协议支持情况确认。

### 4.6 返回与断开

点击系统返回键可从设备页回到扫描首页。若设备主动断开或 BLE 连接异常丢失，设备页会提示 `Device disconnected`，随后自动返回首页。重新操作前需要重新扫描并连接设备。

## 5. 设备参数配置

### 5.1 UDS100 参数

入口：UDS100 设备页的 `Config 1` 表单。

| 参数 | 输入范围 | 说明 |
| --- | --- | --- |
| `Low Threshold(mm)` | 30 - 4500 | 满溢低阈值 |
| `High Threshold(mm)` | 0，或 30 - 4500 | 满溢高阈值；0 表示不启用该阈值 |
| `Report Period(min)` | 1 - 1440 | 状态上报周期 |
| `Gps Period(min)` | 0，或 10 - 1440 | GPS 定位周期；0 表示不启用 |

填写完成后点击 `Config 1` 下发。

### 5.2 DC200 系列参数

入口：DC200/EPS100/MPS100 设备页的 `Config 2` 表单。

| 参数 | 可选项 | 说明 |
| --- | --- | --- |
| `Work Mode` | `Fusion mode`、`Geomagnetic only`、`Radar priority` | 融合、仅地磁、雷达优先三种工作模式 |
| `Report Period(min)` | 1 - 1440 | 状态上报周期 |

填写完成后点击 `Config 2` 下发。状态页的 `Mag X/Y/Z` 与 `Radar Spectrum` 可用于检查模式切换后的传感器数据。

### 5.3 SVC100 基础参数

入口：SVC100 设备页的 `Config 3` 表单。

| 参数 | 可选值 | 说明 |
| --- | --- | --- |
| `Voltage Output Value` | `12V`、`9V`、`5V` | 端口输出电压 |
| `Interface Function` | 7 种脉冲/开关状态组合 | 两个端口的接口功能模式，含防抖变体 |
| `Buffeting duration` | 1 - 255 | 防抖时长 |
| `Auto Power ON` | 自动开关机无效、自动开关机有效 | 自动开关机模式 |
| `Timezone` | `UTC+0` 到 `UTC+12`、`UTC-1` 到 `UTC-12`、`UTC+3.5`、`UTC+5.5` | 设备时区 |
| `Report Period(min)` | 1 - 1440 | 状态上报周期 |

填写完成后点击 `Config 3` 下发。

## 6. SVC100 任务配置

### 6.1 实时任务

入口：SVC100 设备页的 `Config 4` 表单。

| 参数 | 可选值/范围 | 说明 |
| --- | --- | --- |
| `valve` | `1&2`、`1`、`2` | 目标端口 |
| `state` | `OFF`、`OPEN` | 目标状态 |
| `time(s)` | 0 - 65535 | 任务持续时间，单位秒 |
| `pulse` | 0 - 65535 | 脉冲数 |

填写完成后点击 `Config 4` 立即下发实时任务。

### 6.2 定时任务

入口：SVC100 设备页的 `Config 5` 表单。

| 参数 | 可选值/范围 | 说明 |
| --- | --- | --- |
| 任务编号 | `1` - `16`；列表还包含 `FF` | 写入新任务时选择 1 - 16；`FF` 是保留值，App 会拒绝用它配置任务 |
| `valve` | `1&2`、`1`、`2` | 目标端口 |
| `state` | `OFF`、`OPEN` | 目标状态 |
| `pulse` | 0 - 65535 | 脉冲数 |
| 开始/结束时间 | `HH:mm` 时间选择器 | 结束时间必须晚于开始时间 |
| `repeat` | `1` - `7` 多选 | 按星期重复 |

操作：

- 点击开始或结束时间字段弹出时间选择器。
- 点击 `repeat` 字段弹出多选对话框。
- 点击 `Config 5` 写入任务。
- 点击 `Delete` 删除当前选中的任务编号。

## 7. 固件升级 OTA

入口：设备页 `OTA` 配置项。

操作步骤：

1. 展开 `OTA`。
2. 点击 `select file`，从 Android 文件选择器选择固件文件。
3. 选择成功后，升级按钮上方显示固件文件名和字节大小。
4. 确认设备连接稳定、电量充足后点击 `update`。
5. 等待进度条达到 100%；成功后提示 `OTA Successful`。

使用要求：

- Android 11 及以上使用文件选择器返回的 SAF URI 读取固件，不依赖传统外部存储路径。
- 未选择文件或读取失败时点击 `update` 不会开始升级。
- 读取失败会清空已选固件状态，避免误用上一次的旧文件。
- 升级期间不要离开设备页、关闭蓝牙或断开设备电源。

## 8. 调试模式

入口：设备页右上角溢出菜单 `Debug`。

功能：

1. 查看 BLE characteristic 返回的原始数据流，页面自动滚动到底部。
2. 在底部输入框输入自定义命令并点击 `Send` 发送。
3. 蓝牙未连接时发送会提示 `Bluetooth not connect`。

注意：调试页发送的是输入字符串对应的原始字节，不会按十六进制字符串自动组协议帧。调试页打开期间，常规状态轮询和协议解析暂停，返回设备页后恢复。

## 9. 版本与日志

### 9.1 About

入口：首页右上角溢出菜单 `About`。

显示内容：

- 当前 App 版本号和 `versionCode`。
- App 运行日志 `run.log` 的最近内容。

### 9.2 日志位置

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| 运行日志 | 应用私有外部目录 `Android/data/<package>/files/log/run.log`；可用时同步写入公共 `Download/BLETools_log/run.log` | 单文件上限 256 KB，超限后保留较新的一半 |
| 崩溃日志 | 公共 `Download/BLETools_crash/`；失败时写入应用私有 `files/crash/` | 同时保存 `crash_latest.txt` 和带时间戳的归档文件 |

`dev` 构建的包名带 `.dev` 后缀，日志目录中的 `<package>` 会相应变化。

## 10. 构建与安装

Windows 本机推荐使用仓库脚本：

```powershell
./build.ps1 assembleProdDebug
./build.ps1 assembleDevDebug
```

产物路径：

```text
app/build/outputs/apk/<flavor>/<buildType>/
```

常用包：

- `app-prod-debug.apk`：生产包名，debug 签名，可直接安装，适合日常真机验证。
- `app-dev-debug.apk`：开发包名，带 `.dev` 后缀，可与生产包共存。
- `app-prod-release-unsigned.apk`：R8 优化包，但当前未配置 release 签名，安装前需另行签名。

仓库当前 `gradle.properties` 固定指向 Windows JDK 17 路径。在其他系统构建时，需要先按本机 JDK 路径调整该配置，并确保 `local.properties` 指向有效 Android SDK。

## 11. 功能边界

- 一次只支持一个 BLE 连接，不支持批量配置或多设备并行操作。
- 设备识别依赖广播名称；名称不包含支持关键字的设备不会被识别为 UDS100/DC200/SVC100。
- 扫码和手输 DevEUI 都是按 DevEUI 后 6 位匹配广播名称，不是按完整 EUI 精确匹配。
- App 不提供云端配置、账号体系或批量数据管理。
- 代码中有 Excel 工具类，但当前没有界面入口，不能作为已交付的数据导出功能使用。
- 模拟器只能验证 UI 和权限流程，不能替代真实 BLE 功能测试。
