## V6.0.0b1+1（2026-09-21，nix/android-v2 分支，beta）

按 iOS v1 架构整体重构安卓端（M0–M8，UI 1:1 克隆冻结原型）：

**架构**
- 六模块分层：core-protocol / core-device / core-ota / core-ble（纯 Kotlin，零 Android 依赖）+ designsystem + app；工具链升级 AGP 8.7.3 / Kotlin 2.0.21 / Jetpack Compose。
- 旧 XML UI 退役：launcher 切换为 Compose 宿主（旧界面类保留，可经 adb 全限定名回退）。
- 88 个 JVM 测试；金向量测试直读 `shared/fixtures/*.json`（与 iOS 单一真源双端共享）。
- 模拟器首次可验证全 UI 流程（MockCentral + DemoResponder + DemoBootloader 全套演示层）。

**功能（对齐 iOS v1）**
- 扫描页：3 轮扫描生命周期、名称前缀过滤、列表模糊查询、驻留会话+切换确认、重扫健康检测。
- 连接覆盖层（三阶段）+ 设备详情页（会话控制卡/阀状态双通道/实时轮询）。
- 参数配置（UDS/DC/SVC 三家族表单 + 校验 + 确认对话框 + ACK 横幅）。
- 阀门任务：实时开关面板（0x03 状态机+本地倒计时镜像）+ 16 槽定时任务表（0x04/0x05 镜像）。
- 校准页（环境指引/进行中/成功/失败重试流）、OTA 升级页（六段流+镜像三重防线+升级报告）。
- 技术参数页（DC：地磁三轴折线+雷达频谱）、扫码定位流（相机直启+R-32 切换确认）、设置/日志/隐私/语言三态。

**协议行为修正（与现网 3.21 的差异，均有据）**
1. UDS 开关机真载荷（旧版恒 `FFFFFFFF` 从未生效）。
2. 校准/开关机/配置写窗口暂停 1s 轮询（FD-004 RX 单缓冲撞车）。
3. 对时分家族分流：SVC=hkt 帧+ACK / UDS=ASCII 时间戳 / DC 暂禁（固件 tm_mon 缺陷期）。
4. OTA 末包 0xFF 强制落盘 + finish 帧后程（审计 ❌-3/❌-4，测试锁定）。

**已知限制（beta）**
- 真机验证进行中（M7 桥路线：工具链就绪，Mac 蓝牙授权后跑四家族/OTA 真包清单）。
- 维持 debug 签名（正式签名留待下游发布环节；key.jks 已弃用封存）。
- 旧界面类仍编译进包（下一稳定版清理）。
