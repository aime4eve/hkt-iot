# Android v2 · M0 裁决与功能对照表

> 状态：✅ 用户已批准（2026-09-21，规划模式四项裁决 + 里程碑计划批准）
> 权威关系：冻结原型 `docs/ios/design/prototype/index.html` = 双端 UI 唯一事实源；固件源码 = 协议权威；iOS 实现（已过协议审计）= 行为参照；本表 = Android v2 范围基准。

## 1. 四项裁决（2026-09-21）

| # | 事项 | 裁决 |
|---|------|------|
| D1 | UI 技术栈 | **Jetpack Compose**（前置：AGP 7.4→8.x、Kotlin 1.8→2.x 工具链升级）；DesignSystem 组件参数逐条来自原型 CSS，与 iOS 组件同名同参数 |
| D2 | 功能与 UI 范围 | **全功能对齐 iOS v1**：UI 1:1 克隆冻结原型（§9 四步流程双端复用），补齐安卓缺失的全部 iOS v1 裁决功能 |
| D3 | 协议行为基准 | **以 iOS 审计后语义为准**；与现网 V3.21 的行为差异仅限 §3 列出的故意修正，每条可引审计报告/缺陷台账 |
| D4 | 版本与分支 | **v4.0**；分支 `nix/android-v2`；main 冻结为 V3.21 修复线，可随时出 3.2x |

## 2. 安卓现状要点（2026-09-21 盘点基线）

- 16 个 Kotlin 文件 ~5500 行，单扁平包；`Communicate.kt` 全局变量当数据总线（`mDeviceData/mDeviceEvent/mDeviceDataString` top-level var）；GATT I/O、Context 文案混入协议层。
- 纯 XML + findViewById，无 ViewModel/Coroutines/Compose；AGP 7.4.2 / Kotlin 1.8.0 / minSdk 26 / versionName 3.21 (20260906)。
- 测试仅 3 个 JVM 测试（协议解码断言全局变量、扫描过滤纯函数、模板）。
- 死代码：ExcelUtil+POI 依赖、BaseAdapter.kt（全注释）、MyActivity、DropDownActivity、DeviceFeatureConfig。

## 3. 相对现网 V3.21 的故意行为修正（D3 范围，全部有据）

| # | 修正 | 依据 |
|---|------|------|
| F-1 | UDS 开关机改真载荷（现网 `streamDevice(0xFE)` 载荷恒 `FFFFFFFF`，两个分支都不命中——**现网从未真正开关机**，拿无条件 ACK 当成功） | iOS KB 2026-09-20 真机实证 + 协议审计 |
| F-2 | 校准/开关机/配置写窗口暂停 1s 轮询（`setPollingSuspended` 同款）——固件 RX 单缓冲 50ms 空闲判帧，写帧撞轮询被整帧丢弃 | FD-004 + iOS a560368 真机验证；安卓配置/校准失败同源 |
| F-3 | 对时分家族：SVC=hkt 帧+ACK 等待；UDS=ASCII `syncDeviceTimestamp:`（无回执）；DC=禁用并隐藏入口（固件 tm_mon+1 写错月份） | 协议审计 ❌-1/❌-2；iOS 已实现语义 |
| F-4 | OTA 末包 cmd=0xFF 强制落盘 + ACK(3,0) 后 finish 帧（安卓现网已符合，v2 引擎化后必须保留并有测试锁定） | 协议审计 ❌-3/❌-4；Android Communicate.kt:770-778/395-397 |

## 4. 功能对照表（逐条处置）

处置代号：**沿用**（行为不变）/ **对齐**（改造成 iOS 语义）/ **修正**（bug 修复，§3 有据）/ **补齐**（安卓缺失新增）/ **删除**（死代码）。

### 4.1 扫描与连接

| 能力 | 安卓 V3.21 现状 | iOS v1 现状 | v2 处置 |
|---|---|---|---|
| 扫描生命周期 | 3 轮×10s、轮间 500ms、低延迟模式 | 3 轮×10s 增量累积、第 3 轮自动停保留结果、轮内进度条、再点清空重开 | 对齐（f457d2c 终版语义） |
| 入列过滤 | RSSI 阈值 + 空名过滤 | RSSI + 四芯片前缀过滤（`ScanOptions.isListable` 规则唯一出处） | 对齐+补齐（前缀过滤设置页可配） |
| 列表模糊搜索 | 无 | R-33 常驻搜索框，广播名 contains 忽略大小写，与类型过滤 AND | 补齐 |
| 扫码定位 | ZXing 扫码→目标扫描 | ⌖ 相机直启 QR→16 位 DevEUI 后 6 位匹配→自动连接；无效码红字继续扫 | 对齐 |
| 手输定位 | Input EUI 菜单（默认前缀 0095690） | 已废弃（3522ca4 重构删除手输弹层） | 对齐 iOS（删手输入口） |
| 连接流程 | BLEUtils 直连，MTU 512→发现服务→订阅 | 三阶段状态机（预算 10/5/5s）+ P-02 覆盖层 + 取消 | 对齐（ConnectOrchestrator 移植） |
| 会话模型 | 单页模型，无驻留 | 返回=驻留 / 断开=显式释放（R-31）/ 切换确认框（R-32）/ 重扫健康检测（>5s 无轮询心跳判失联→自动重连≤3） | 补齐 |
| 定位扫描会话 | 同一会话复用 | startLocate 先 stop 再 start（CoreBluetooth 同设备只报一次的去重语义对策） | 补齐（安卓 Nordic scanner 行为需 M7 真机核对） |
| 权限引导 | 运行时权限+`@SuppressLint("MissingPermission")` | P-08 四态引导门（初始化/拒绝引导去设置/蓝牙关/不支持） | 对齐 |
| 蓝牙能力检测 | 隐式 | BLEAvailability 五态 | 对齐 |

### 4.2 设备详情与会话

| 能力 | 安卓现状 | iOS 现状 | v2 处置 |
|---|---|---|---|
| 状态轮询 | StreamThread 500ms 睡眠轮询全局变量 | DeviceSession 1s 快照 + stale 4s + linkLost | 对齐（架构重构） |
| TLV 解码 | streamRev() 手写偏移+Context 取文案 | HKTResponseParser TLVSizeTable（未知类型 unknownTail） | 对齐（文案映射上移 UI 层） |
| 开关机 | 0xFE 载荷 FFFFFFFF（bug）；无确认框 | 真载荷+关机确认弹窗+关机屏+ACK 成功释放会话回首页（09-20 裁决） | 修正+对齐 |
| 校准 | 直接发命令（撞轮询） | P_cal 校准页：直接跑无二次确认、成功停 3s 自动返回、失败弹窗重试；UDS 角度/EPS·MPS·DC 磁力计/SVC 无入口 | 对齐+修正（F-2 停轮询窗口） |
| 对时 | 全家族同一 hkt 帧（UDS/DC 固件死分支，实际无效） | 分家族（F-3）；TIME 卡三态结果（完成/已发送/不支持） | 修正+对齐 |
| 技术参数 | 地磁三轴/雷达频谱嵌详情网格 | 独立 P-03b：判定卡+30 组折线+10 段频谱 | 对齐 |
| Debug | DebugActivity 原始 hex 台 | 版本行 7 击开启 Debug（页按原型） | 对齐（保留能力，UI 按原型） |
| SVC 阀门任务 | 对话框表单（实时+定时+删除） | 开关面板（每路阀开/关大按钮、当前态高亮、剩余量满格递减倒计时条、默认 60s/100 脉冲）+16 槽定时任务表+本地镜像（固件无 BLE 回读） | 对齐 |
| 配置 | ExpandableList 组头内嵌 dialog_config_* 表单 | P_config 三家族表单：前置校验（UDS 整包拒绝语义/SVC 时区 0-26）、编辑草稿独立于轮询刷新、写窗口停轮询 | 对齐+修正 |
| OTA | backBootLoaderBuf 128B 分包+末包补 FF | OTAEngine 状态机：进入双帧→启动节拍→逐包停等→ACK(1,0) 从包 0 重传≤2→finish 帧；离开保护；升级报告 | 对齐（引擎化；F-4 测试锁定） |
| 定时任务星期 | repeat 位掩码（V3.18 修过 2B 脉冲） | bit0=周一…bit6=周日、结束>开始 App 层校验 | 沿用+补校验 |
