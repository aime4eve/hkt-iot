
状态变体：② 轮询暂无响应=徽章转"最后更新 3 秒前 · 正在重试"，字段保留最后有效值；②b 数据异常=顶部错误横幅"数据格式异常，已显示上次有效值 [导出日志] [重连]"；③ 已断开=全页置灰 + "连接已断开 [重新连接]"；④ 蓝牙关闭=横幅 + 跳 P-08；⑤ 升级模式=`0xFF` 无版本响应 → 全页替换为"设备处于升级模式：上次升级未完成，请重新执行固件升级 [去升级]"。

UDS100/SVC100 复用同骨架，仅字段网格内容不同（需求 §7.1/7.3 字段集），由 DeviceRegistry 字段描述符驱动。

## 线框评审核对清单

1. 每页状态集与 UI 设计计划 §3 一一对应，无"空白态"。
2. 十类错误全部有落点（UI 计划 §5.1 映射表）。
3. OTA 六阶段 + 返回保护 + 结果页齐备；100% 处明确标注"尚未完成"。
4. 四类设备差异仅体现在字段网格与能力入口，不产生新骨架。
5. 无协议术语出现在 P-01~P-05/P-07/P-08（P-06 面向工程人员除外）。
