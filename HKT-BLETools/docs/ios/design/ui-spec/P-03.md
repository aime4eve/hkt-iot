## 1. 页面结构（DOM 即结构，自上而下）

```
statusbar（iOS 用系统状态栏，不实现假 9:41）
sessionbar                ← 页头=会话控制卡；原型无导航栏！iOS 必须 .toolbar(.hidden) 隐藏系统导航栏
  ├─ session-top:         device-name(左) + 状态 badge(右)
  ├─ device-meta:         "固件 {fw} · {电量/电压}"（右对齐）
  └─ session-actions:     2×2 按钮：返回 | 首页 | 固件升级 | 断开连接(danger)
body（滚动区 padding: 0 16px 24px）
  ├─ [仅 abnormal] banner err：⚠︎ 文案 + 右侧 act「导出日志」
  ├─ section「状态（实时轮询）/ Status (live polling)」
  ├─ SVC100 → svc-module(阀状态) + fieldgrid(5 字段)
  ├─ 其他家族 → fieldgrid（DC 4 字段 / UDS 13 字段）
  ├─ section「设备操作 / Device actions」
  └─ ops-panel：电源整行 + ops-grid(全宽 op-card ×N)
[浮层] 关机确认 HKTDialog / 断开确认 HKTDialog（mask 全屏、dialog 296px）
```

**早退视图（优先于上面全部内容）：**
1. `upgradeMode` → 居中 ⏫(44px) + 标题(17px/600) + 副文案(13px text2 行高1.5) + 按钮「去重新升级」→ 跳 OTA 页。（iOS v1 快照无升级模式标志 → 架构预留，渲染分支不实现）
2. `!powerOn`（快照 power==0）→ 居中 ⏻(46px) + 「已关机」+ 按钮「开机」→ 发 0xFE 开机。
3. `disconnected`（linkLost）→ 居中 📵(44px) + 「连接已断开」+ 按钮 t("retry")。

## 3. 组件规格（逐条数值）

### 3.1 SessionControlCard（.sessionbar）
- 容器：card 底、`line 82%` 描边、**r12**、外边距 `0 16 12`、内边距 `13 14`、卡片阴影。
- session-top：水平 space-between；设备名 **23px / 字重750 / 行高1.1**；右侧 badge。
- badge：12px/600，padding `3 9`，r999，`ok 15%` 底 + ok 字色，前置圆点 dot **7×7** 同字色。
  - ready=ok「已连接 · 轮询正常」；stale=warn「最后更新 {s} 秒前 · 正在重试」；abnormal=err「响应数据异常（未知类型），已显示可解析字段」；reconnecting=warn「自动重连中（第 {n}/3 次）」。
- device-meta：**右对齐**，margin `5 0 12`，12px text2 等宽数字。内容=`固件 {fw} · {batt}`；batt：UDS100=`电压 {mv} mV`，其余=`电量 {pct}%`。
- session-actions：2 列 grid gap 6；按钮高 **34**、padding `0 4`、`line` 描边、r8、card2 底、12px/650、超长省略号；顺序=返回/首页/固件升级/断开连接；danger 变体=`err 8%` 底、`err 24%` 描边、err 字色；置灰=opacity .4。

### 3.2 SectionHeader（.section）
- 11px text2 字重700 字距 .05em；margin `16 4 8`；文字右侧接 flex:1 分隔线（高1 `line 76%`）。

### 3.3 FieldTile（.field）
- card 底、`line 82%` 描边、r10、padding `10 12`、**min-height 70**、纵向 space-between、卡片阴影。
- .k 标签：11px/600 text2，单行省略。
- .v 值：**16px/650**，margin-top 4，任意处换行，行高 1.25，等宽数字。
- 单位 span：11px text2/400，margin-left 2。
- fieldgrid：2 列 gap 8；**奇数个字段时最后一个独占整行**。

### 3.4 ChannelModule（.svc-module，仅 SVC100）
- 容器：card 底、`line 82%` 描边、r10、margin-bottom 8、padding 12。
- head：水平 space-between gap 8 margin-bottom 10；标题 `.svc-module-title` 13px/700；右侧 tag：10px/650 text2、card2 底、`line` 描边、r999、padding `3 7`（内容=`含稳定时长`/`标准模式`，判定 `port & 0x80`）。
- channel-grid：2 列 gap 8。channel 卡：**card2 底、`line 72%` 描边、r8、padding 10**。
  - head：通道名 12px/700 text2（`阀 1`/`阀 2`）+ StatePill（11px/700 r999 padding `3 7`；on=`ok 14%`底 ok字、off=`text2 10%`底 text2字；前置 dot 7×7；文案=`开启`/`关闭`，判定 valve{n}State==1）。
  - kpis（纵排 gap 8，margin-top 9）：每项 label 10px/600 text2 + 值 14px/650 行高1.2 等宽数字：
    1. 插入检测 → `是`/`否`（valve{n}Inserted==1）
    2. 脉冲计数 → `toLocaleString()` 千分位
    3. 端口功能 → 该路开关模式? `开关控制` : `PWM 控制`（V1: mode∈{1,3}；V2: mode∈{2,3}，mode=`port&0x03`）

### 3.5 Banner
- padding `10 12`、r10、13px、行高1.4、margin-bottom 11；err=`err 12%` 底 err 字；warn 同理。
- abnormal 内容：`⚠︎ {abnormal 文案}` + 右侧 act「导出日志」（600 字重，跳日志页；iOS v1 无日志页 → 预留占位动作）。

### 3.6 OpsPanel（.ops-panel）
- 容器：card 底、`line 82%` 描边、r10、overflow hidden、卡片阴影。
- ops-power：水平 gap 12、**min-height 58**、padding `0 14`、底边 `line 72%`；label 15px/650；state(flex:1) 12px text2；右侧 Switch（44×26 r13，off=`fill` 底、on=`ok` 底；旋钮 22×22 白色、边距 2、on 时左移 20）。
- ops-grid：2 列 gap 8、padding 10、**card2 底**。
- OpCard（全部 wide=独占整行、min-height 62，非 wide 的 78 不用于本页）：内 grid `auto 1fr auto` gap 10、padding 11、card 底、`line 82%` 描边、r8、水平居中。
  - op-badge：**38×38 r10** 等宽 10px/700 字距.04em；默认=`info 10%`底 info 字；warn 变体=`warn 12%`底；ok 变体=`ok 12%`底。
  - op-copy：纵排 gap 3；title 13px/650 行高1.2；desc 11px text2 行高1.25。
  - 尾部：跳转型=`op-go` "›" 17px text2；TIME 卡=`op-action` 胶囊（padding `6 8` r999 `info 10%`底 info 字 11px/700）。
- 本页 tile 顺序与变体：
  1. **CAL**（warn）— UDS100=「倾角校准」，DC 家族(MPS/EPS)=「磁力计校准」，SVC100 无此卡

  3. **CFG**（默认）— 「参数配置」desc「上报 / 端口 / 时区」
  4. **TIME**（ok）— 「时间同步」desc=实时时钟 `yyyy-MM-dd HH:mm:ss`；action=`同步`/`同步中`(发送中禁用)/`完成`(2.6s 后回落)
  - 校准运行中：全部 tile+电源行置灰（opacity .45）。

### 3.7 HKTDialog（关机/断开确认）

## 6. 与原型的一致性裁定（实现时已处理）

1. **⚠️ 原型文案 bug（冻结源自带）**：disconnected 居重视图的按钮用 `t("retry")`，而 retry 键已被 OTA 段覆写为「重新升级/Retry Update」。语义应为重试连接。**实现取「重新连接/Retry」并在下次原型修订时提请用户裁决**（§8：改原型需确认）。
2. **导航栏**：原型 P_detail 无 navbar（会话卡即页头，返回/首页在会话条）。iOS 实现隐藏系统导航栏（`.toolbar(.hidden, for: .navigationBar)`），返回/首页由会话条按钮承担。
3. **reconnecting 状态**：iOS v1 DeviceSession 尚无自动重连状态机（R-6 待实现）→ 徽章分支已按规格写好，状态源接入后自动生效。
4. **upgradeMode 状态**：轮询快照无升级模式字段 → 渲染分支不实现（架构预留），接入后按 §1-早退视图1 渲染。
5. **U+FF08 等宽**：值用 SwiftUI `.monospacedDigit()`（对应 tabular-nums），不用全等宽字体（原型值字体是 SF Pro 非等宽，只有数字等宽）。
