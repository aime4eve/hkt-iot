## 1. 页面结构（DOM 即结构，自上而下）

```
navbar（大标题 20px/700，无返回键）
  └─ navright：linkbtn「⌖ 定位」(margin-right 12) + linkbtn「⚙︎」
body（padding 0 16 24）
  ├─ .row 扫描状态行：label「扫描中… 已发现 N 台 / 扫描完成 · N 台」(15px) + linkbtn「停止 / 重新扫描」(右)
  ├─ liveCard 驻留会话卡（R-32，仅活会话时；置顶）：名称+小badge「已连接」/ ID 行 / 右 linkbtn「›」；点击=回详情
  ├─ 设备卡 ×N（.card hcard）：名称(15px/700) / ID …XXXX · {rssi} dBm(12px text2) / 右 RSSI 条；点击=deviceCardClick
  ├─ 空态（!扫描 && 无设备 && 无驻留）：.center 📡(44px) + 「未发现支持设备」(17px/600) + 副文案(13px text2) + btn secondary「重新扫描」(宽自适应 padding 10 26)
  └─ recent 最近设备（列表空 && 无驻留 && 有上次会话）：section「最近设备」+ .card hcard：名称 / ID · 昨天(12px) / 右 linkbtn「↻」；点击=标准连接
[浮层] switchTo 切换确认 HKTDialog（R-32 确认框自动切换）
```

**点击语义（deviceCardClick，原型 L581）**：
1. 活会话 + 点同一设备（验活 phase=ready）→ 直接进详情（不重连）；
2. 活会话 + 点其他设备 → `switchTo` 切换确认框 → 确认=原子释放旧会话 + 标准连接新设备；
3. 无活会话（或会话失联）→ 标准连接（停扫 → 连接覆盖层 P-02）。

**重扫健康检测（toggleScan，R-32 补充）**：活会话时点「重新扫描」，以最后成功轮询距今 >5s 判定无蓝牙信号 → 自动重连（≤3 次），不进入扫描。

## 2. 组件规格（逐条数值，未列出处与 P-03 规格卡 §2/§3 相同）

### 2.1 NavbarLarge（.navbar 大标题版）
- 标题 20px/700 字距 0；padding `40 16 10`（iOS 安全区下约 10）；无返回键。
- 右侧 linkbtn ×2：`.linkbtn` = info 字色 14px/600、`info 9%` 底、r8、padding `6 9`；「⌖ 定位」margin-right 12，「⚙︎」无文字仅符号。

### 2.2 ScanStatusRow（.row）
- `.row`：card 底、`line 82%` 描边、r10、padding `12 14`、margin-bottom 9、阴影。
- label 15px（扫描中文案带实时数量）；右 linkbtn「停止」/「重新扫描」（14px/600 info）。

### 2.3 ScanDeviceCard（.card + .hcard）
- `.card`：card 底、`line 82%` 描边、r10、padding `13 14`、margin-bottom 11、阴影。
- `.hcard`：水平布局 gap 12。
- 名称 15px/700（继承正文字号）；第二行 12px text2 margin-top 2（等宽数字）。
- 驻留卡：名称右侧小 badge「已连接」（badge 12px/600 padding `2 8` margin-left 6，ok 15% 底 + dot 7px）；右 linkbtn「›」。
- 普通卡右 RSSI 条（.rssi）：4 根竖条宽 3 gap 2 圆角 1，高度 4/7/10/14；亮=ok 色、灭=fill 色。亮度映射（原型 L567）：`rssi > -70 → 4 亮；> -85 → 3 亮；否则 2 亮`。
- ID 显示格式：`ID …{后4位}`（原型 id 形如 …9C01）；普通卡追加 ` · {rssi} dBm`。

### 2.4 空态（.center）
- 📡 44px；标题 17px/600；副文案 13px text2 行高 1.5；按钮 `.btn secondary`（card 底 line 描边 text 字 16px/650 r8）宽自适应 padding `10 26`。

### 2.5 最近设备（recent）
- `.section`（同 P-03 SectionHeader）「最近设备 / Recent」。
- 卡片同 .card hcard；第二行 `ID …XXXX · 昨天`；右 linkbtn「↻」。仅在列表空且无驻留且存在上次会话时显示。

### 2.6 切换确认框（R-32，.dialog 296/r18）
- 标题「切换设备？」；正文（含粗体设备名）：`当前已连接 {A} {idA}。切换将断开当前会话并连接 {B} {idB}。`
- 按钮：`.btn secondary`「取消」+ `.btn`（info 主色）「切换并连接」。（注意：确认键是主色 info 而非 danger。）

## 3. 状态与数据

| 状态 | 来源 | 显示 |
|---|---|---|
| 扫描中 | isScanning | 「扫描中… 已发现 N 台」+「停止」 |
| 扫描完成 | !isScanning | 「扫描完成 · N 台」+「重新扫描」 |
| 驻留会话 | activeSession + residentDevice | liveCard 置顶；列表中隐藏同设备普通卡 |
| 入列规则 | ScanOptions（R-1/SP-1） | RSSI ≥ 阈值(-80) && 前缀命中；EPS100 -91 被过滤 |
| 空态 | !扫描 && 无设备 && 无驻留 | 空态视图 |
| 最近设备 | lastSession（断开释放时记录） | 仅空列表时显示 |

## 5. 一致性裁定

1. **⚠️ 原型冻结源 EN 字典缺 `switchT`/`switchGo`**（仅 ZH 有，EN 渲染会是 undefined）→ iOS 按 ZH 语义取英文，下次原型修订提请用户补齐。
2. **ID 后缀**：原型广播 id 形如 `…9C01`（真实 EUI 后 4 位）；iOS 系统不暴露设备 MAC，用系统标识符后 4 位大写呈现（真机广播名本身含 EUI，主键以名称为准）。
3. **⚙︎ 设置入口**：按钮按原型渲染；设置页（P-07）在批量队列中，到货前为占位动作。
4. **⌖ 定位入口**：按钮按原型渲染；点击打开现有 LocateFlowView（定位 UI 细节属批量队列中的"定位 UI"步骤）。
5. **重扫健康检测**：iOS 无 ≤3 次重连状态机（R-6 待实现），先按"无心跳 → 原子释放 + 原身份重连一次"落地，R-6 到货时升级。
