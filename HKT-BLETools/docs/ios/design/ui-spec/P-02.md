## 1. 页面结构（DOM 即结构）

```
.overlay（全屏，bg=--bg，纵向布局）
  ├─ .center（弹性居中，gap 10，水平 padding 32）
  │    ├─ 🔗 大图标 44px
  │    ├─ 设备名 "{name} …{id后4位}"（.big 17px/600）
  │    ├─ steps(3)（.steps：横向居中 gap 6，margin 8 0）
  │    └─ 阶段文案（.sub 13px text2 行高1.5）
  └─ 取消按钮区（padding 24）：.btn secondary 全宽
```

## 2. 组件规格

### 2.1 Steps（.steps）
- 3 根横条：宽 24、高 5、圆角 3、间距 6、整体居中；上下 margin 8。
- 亮=--info，灭=--fill。点亮规则（原型 `i<=connStep`）：阶段 0 → 1 亮、1 → 2 亮、2 → 3 亮。

### 2.2 阶段文案（i18n）
| 阶段 | ZH | EN |
|---|---|---|
| 0 | 正在连接 | Connecting |
| 1 | 正在发现服务… | Discovering services… |
| 2 | 正在订阅通知… | Subscribing to notifications… |

### 2.3 取消按钮
- `.btn secondary`：全宽、padding 13、r8、card 底、`line` 描边、text 字色、16px/650；容器 padding 24。
- 取消语义（cancelConn）：终止连接并回扫描页（不做驻留）。

### 2.4 设备名显示
- 格式 `{广播名} …{id 后 4 位}`（原型 `(S.id||"9C01").slice(-4)`）；iOS 用系统标识符后 4 位大写。

## 3. 状态

| 状态 | 显示 |
|---|---|
| 连接中（outcome=nil） | 🔗 + 设备名 + steps(亮 phaseIndex+1) + 阶段文案 + 取消 |
| 成功/取消 | 直接关闭覆盖层（成功→置驻留+进详情；取消→回扫描页） |
| 失败 | 见 §5-1 |

## 4. 一致性裁定

1. **失败态原型未设计**（原型演示流程恒成功）：iOS 保留既有失败信息（超时/缺服务/断开等原因）与重试/返回行为，控件用原型 `.btn primary`（重新连接）与 `.btn secondary`（返回）渲染，居中区改显失败文案（13px，err 色）。
2. 覆盖层以 `fullScreenCover` 呈现，弹出即 `start()`（此前连接不启动的根因，保持）；环境对象需显式 `.environment(model)` 重新注入。
