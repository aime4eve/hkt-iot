# BLETools — IoT 设备蓝牙配置工具

BLETools 是一款 Android 蓝牙配置应用，用于扫描、连接、配置和固件升级 HKT 系列 BLE IoT 设备。通过自定义二进制协议与设备通信，支持多类传感器和控制器的完整配置管理。

## 支持的设备类型

| 设备类型 | 说明 | 名称匹配 |
|---------|------|---------|
| **UDS100** | 超声波垃圾桶满溢监测传感器 | UDS100 |
| **DC200**（地磁系列） | 地磁/雷达车位传感器 | DC200、EPS100、MPS100 |
| **SVC100** | 双电磁阀控制器 | SVC100 |

> **说明：** DC200、EPS100、MPS100 同属地磁系列传感器，配置界面完全一致，应用内统一按 DC200 类型处理。

## 核心功能

### 📡 设备扫描与连接

- **BLE 低延迟扫描**：3 周期 × 10 秒多轮扫描，覆盖范围广
- **扫描过滤**：支持 RSSI 信号强度阈值过滤、隐藏无名称设备
- **二维码扫码连接**：扫描设备二维码自动匹配并连接（基于 ZXing）
- **设备列表实时刷新**：DiffUtil 优化列表加载性能

### ⚙️ 设备配置

每种设备类型提供专属配置界面：

**UDS100（满溢传感器）**
- 满溢低/高阈值设定（30–4500 mm）
- 上报周期配置（1–1440 分钟）
- GPS 定位周期配置（10–1440 分钟）
- 高温报警功能

**DC200 系列（地磁/雷达车位传感器，含 EPS100、MPS100 等）**
- 工作模式选择（地磁模式 / 雷达优先模式）
- 上报周期配置（1–1440 分钟）
- 三轴磁场（X/Y/Z）和雷达频谱数据实时展示

**SVC100（电磁阀控制器）**
- 电压输出值选择
- 接口功能模式配置
- 抖动持续时间设定（1–255）
- 自动上电开关
- 时区设置
- 上报周期配置（1–1440 分钟）

**通用配置项**
- 实时任务下发
- 定时任务管理（创建/删除）
- 时间戳同步（部分设备不支持）
- 设备校准
- 电源开关控制

### 📊 实时状态监测

- 设备状态每秒自动轮询刷新，无需手动操作
- 实时展示：电池电量、温湿度、距离/满溢状态、GPS 经纬度、地磁三轴、雷达频谱等遥测数据
- 状态数据动态刷新

### 🔧 固件升级（OTA）

- 支持通过 BLE 进行固件在线升级
- 128 字节分包传输，带进度显示
- 固件文件选择与一键升级

### 📋 数据导出

- 支持将设备数据导出为 `.xls` 格式（Apache POI）
- 便于数据归档与分析

### 🐛 诊断与调试

- **About 面板**：查看应用版本号、浏览系统错误日志
- **Debug 模式**：查看原始 BLE 通信数据，用于协议级调试
- **崩溃日志**：自动捕获异常并记录，便于问题排查

### 🔄 其他特性

- 断连自动检测与提示，防止闪退
- 多轮扫描策略，提高设备发现率
- 中英双语界面
